> **En bref**
> - Le code confidentiel est un code à **5 chiffres** envoyé avec la carte grise. Il est réclamé sur la voie officielle pour un changement d'adresse ou un duplicata, sauf si la démarche est faite pour soi-même avec **FranceConnect**.
> - Un nouveau code peut être demandé à tout moment, gratuitement. Il part **par courrier à l'adresse enregistrée** sur la carte grise, ce qui bloque la personne qui a déménagé depuis.
> - Les cartes grises de l'ancien format **FNI** (immatriculation 123 AB 45) n'ont jamais eu de code confidentiel : leur titulaire n'a rien perdu.
> - Un professionnel habilité par le Ministère de l'Intérieur n'a pas besoin de ce code. cartegrise.com (habilitation **n° 9744**, agrément **n° 14871**, depuis 2009) annonce le traitement et le certificat provisoire **sous 12 à 24 h** après réception du dossier complet.

La démarche est lancée en ligne : changement d'adresse après un déménagement, duplicata après une perte, déclaration de vente. Les champs sont remplis, puis l'écran réclame un code confidentiel à cinq chiffres. Ce code n'a jamais été vu, ou il est parti à la poubelle avec l'enveloppe de la carte grise. La démarche s'arrête là.

Ce blocage est fréquent, et il a une explication simple. Le code confidentiel sert à authentifier la carte grise lors des démarches faites sur le site de l'État. Il n'existe qu'à un seul endroit, et il ne concerne pas toutes les cartes grises. Surtout, il existe trois façons d'avancer quand il manque : en redemander un, s'identifier avec FranceConnect, ou confier le dossier à un professionnel habilité. L'une de ces voies n'exige aucun code.

## Les trois voies quand le code manque

| Critère | Demander un nouveau code | S'identifier avec FranceConnect | Passer par un professionnel habilité (ex. cartegrise.com) |
|---|---|---|---|
| **Code confidentiel exigé** | Oui, le nouveau code remplace l'ancien | Non, pour une démarche faite pour soi-même | Non pour un changement d'adresse ou un duplicata |
| **Délai de la solution** | Email sous 24 h maximum pour une demande faite pour soi, sinon courrier seul, à l'adresse inscrite sur la carte grise | Immédiat : la démarche se poursuit sans attendre | Traitement et certificat provisoire sous 12 à 24 h après réception du dossier complet |
| **Démarches restant à faire soi-même** | Attendre le code, puis reprendre la démarche en ligne | Mener toute la démarche sur le site de l'ANTS | Transmettre les justificatifs, le dossier est contrôlé avant enregistrement |
| **Coût** | Gratuit | Gratuit (hors taxes éventuelles) | Frais de service : 44,90 € pour un changement d'adresse, 54,90 € pour un duplicata, en plus des taxes |
| **Compte à créer** | Compte usager ANTS | Compte chez un fournisseur d'identité FranceConnect (impots.gouv.fr, Ameli...) | Compte classique, email et mot de passe |
| **Verdict** | Gratuit, mais dépend de l'envoi postal et de la concordance avec le fichier | Immédiat, mais seulement pour sa propre démarche | Payant, mais ne dépend d'aucun code ni d'aucun courrier : la voie rapide quand la démarche concerne un tiers ou une personne qui a déménagé |

Ces trois voies ne s'opposent pas. Elles répondent à des situations différentes, que les sections suivantes détaillent une par une.

## Où trouver le code confidentiel

Le code confidentiel est apparu avec la dématérialisation des démarches d'immatriculation, dans le cadre du Plan préfectures nouvelle génération (PPNG). Depuis, les démarches se font en ligne, et le site de l'État doit s'assurer que la personne qui modifie une carte grise en a bien le droit. C'est le rôle de ce code : authentifier le certificat d'immatriculation lors d'une démarche sur le site de l'ANTS.

Il s'agit d'un code unique de cinq chiffres. Il est délivré au moment de l'édition de la carte grise, après l'enregistrement du véhicule dans le système d'immatriculation des véhicules (SIV). Chaque certificat a donc le sien, et il accompagne le titre depuis son impression.

### Sur la lettre qui accompagne la carte grise

Le code figure au milieu de la lettre qui accompagne la carte grise à sa réception, imprimé en caractères gras. Il ne se lit pas sur le certificat lui-même : seule cette lettre le porte.

C'est aussi ce qui explique la plupart des blocages. La lettre ressemble à un simple courrier d'envoi, et beaucoup de titulaires la jettent en rangeant la carte grise dans la boîte à gants. Le réflexe utile, à chaque nouvelle carte grise, est de conserver cette lettre avec les papiers du véhicule, ou de noter le code dans un endroit sûr.

Avant de conclure que le code est perdu, il vaut la peine de vérifier deux choses : la date d'édition de la carte grise, car une réédition (duplicata, changement de titulaire) s'accompagne d'une nouvelle lettre, et le format de l'immatriculation, qui dit si un code a jamais existé.

### Les cartes grises FNI qui n'en ont jamais eu

Le code confidentiel ne concerne que les cartes grises du système actuel, le SIV, reconnaissables à une immatriculation au format AB-123-CD. Les cartes grises de l'ancien fichier national des immatriculations (FNI), au format 123 AB 45, n'en ont jamais reçu.

Le titulaire d'une carte grise FNI n'est donc pas en faute, et il n'a rien perdu : il n'y a tout simplement rien à retrouver. Il est inutile de chercher la lettre ou de demander un nouveau code pour ce certificat.

Ce cas a une conséquence pratique. Pour un changement d'adresse sur un véhicule FNI, la fiche service-public.gouv.fr « Changer l'adresse sur son certificat d'immatriculation » précise qu'un nouveau certificat est alors délivré, pour une redevance de 2,76 €. Le code confidentiel arrivera avec cette nouvelle carte grise.

## Demander un nouveau code : pourquoi ça ne part pas toujours

Sur le site de l'ANTS, un bouton placé à droite de la case « code confidentiel » permet d'en demander un nouveau. Il faut alors renseigner des informations sur la carte grise et sur l'identité du titulaire. La démarche est gratuite et peut être faite à tout moment.

La fiche service-public.gouv.fr « Vendre ou donner son véhicule » précise le mode d'envoi. Pour une demande faite pour soi-même, le nouveau code est envoyé par email dans un délai maximum de 24 heures, et par courrier à l'adresse inscrite sur le certificat d'immatriculation. Pour une demande faite pour quelqu'un d'autre, il part uniquement par courrier, à cette même adresse.

Deux situations empêchent pourtant le code d'arriver.

- **L'adresse n'est plus la bonne.** Le courrier part à l'adresse enregistrée sur la carte grise. Une personne qui a déménagé sans mettre à jour son certificat le recevra à son ancien domicile. C'est un cercle fermé : il faut le code pour changer l'adresse, et l'adresse à jour pour recevoir le code par courrier.
- **Les informations ne concordent pas.** Si les données saisies diffèrent de celles enregistrées dans le système d'immatriculation, aucun nouveau code n'est délivré. Une erreur dans la date de naissance inscrite au fichier suffit à bloquer la demande.

La page d'aide de cartegrise.com consacrée au code confidentiel signale aussi que l'envoi des nouveaux codes connaît parfois des dysfonctionnements. Dans ce cas, la démarche reste en attente sans que le titulaire sache quand elle pourra reprendre.

Demander un nouveau code reste la bonne première option quand l'adresse de la carte grise est à jour, que la démarche est faite pour soi et que rien ne presse. Dans les autres cas, les deux voies suivantes évitent l'attente.

## FranceConnect : la condition qui change tout

FranceConnect est le dispositif d'identification et d'authentification de l'État pour les services en ligne. Il permet de se connecter au site de l'ANTS avec un compte déjà existant chez un fournisseur d'identité, par exemple impots.gouv.fr ou Ameli. FranceConnect transmet alors les informations d'identité nécessaires au site d'immatriculation.

La page d'aide « code confidentiel » du site d'immatriculation de l'État en tire la conséquence : l'identification par FranceConnect dispense de fournir le code, pour une demande faite pour soi-même. La dispense vaut notamment pour le changement d'adresse et le duplicata. La fiche service-public.gouv.fr sur la vente d'un véhicule l'applique aussi à la déclaration de cession : l'identification par FranceConnect évite de renseigner le code.

Il ne s'agit pas d'une astuce ni d'un contournement. C'est une règle de l'administration : FranceConnect apporte déjà la preuve de l'identité du demandeur, le code n'a plus d'utilité. L'effet est immédiat, sans courrier à attendre.

La condition est stricte. La dispense ne joue que si le demandeur est le titulaire de la carte grise. Dès que la démarche est faite pour un conjoint, un parent ou un enfant, FranceConnect prouve l'identité de celui qui se connecte, pas son droit à modifier la carte grise d'un autre. Le code redevient alors indispensable.

Pour en savoir plus sur le fonctionnement de ce dispositif dans les démarches d'immatriculation, cartegrise.com publie une page dédiée à [FranceConnect et carte grise](https://www.cartegrise.com/france-connect). Le site se présente aussi comme partenaire du système d'authentification FranceConnect depuis 2019.

## Quand la démarche est faite pour quelqu'un d'autre

C'est un cas particulièrement bloquant. Un enfant qui gère la carte grise d'un parent âgé, un conjoint qui s'occupe du véhicule du foyer, un proche qui prend en charge un changement d'adresse : sur le site de l'ANTS, la démarche se fait avec le bouton « Pour quelqu'un d'autre », et le code confidentiel du titulaire est exigé.

FranceConnect ne lève pas cette exigence. Reste la demande d'un nouveau code, mais celui-ci part uniquement par courrier à l'adresse inscrite sur la carte grise. Si le titulaire a déménagé, ou si le courrier n'arrive pas, la démarche reste bloquée.

La troisième voie prend ici tout son sens. Un professionnel habilité par le Ministère de l'Intérieur et agréé par le Trésor public accède directement au système d'immatriculation des véhicules. Il n'a pas besoin du code confidentiel pour traiter un changement d'adresse ou un duplicata : le titulaire le mandate, transmet ses justificatifs, et le dossier avance sans attendre de courrier.

Une exception mérite d'être connue. Pour enregistrer une déclaration de cession, la fiche service-public.gouv.fr « Vendre ou donner son véhicule » indique que le vendeur qui mandate un professionnel lui communique le code confidentiel, pour des raisons de sécurité. Le vendeur qui fait la déclaration lui-même peut, lui, s'identifier avec FranceConnect.

cartegrise.com fait partie de ces professionnels. Il est habilité par la préfecture (n° 9744) et agréé par le Trésor public (n° 14871) depuis le 15 avril 2009, et revendique plus d'1 million de dossiers traités, avec des notes de 4,6 et 4,5 sur 5 sur plus de 32 000 avis. Il s'agit d'un prestataire privé, distinct de l'ANTS. Le site publie une page complète pour [faire sa carte grise sans le code confidentiel](https://www.cartegrise.com/carte-grise-ants/code-confidentiel).

Le déroulé tient en trois étapes : calculer le coût de la démarche, valider la demande, puis transmettre les justificatifs à partir d'une liste personnalisée. Le dossier est vérifié avant enregistrement, avec une relance en cas d'anomalie. Le traitement et le certificat provisoire interviennent sous 12 à 24 h après réception du dossier complet, puis l'Imprimerie nationale envoie la carte grise définitive environ 2 à 3 jours après le certificat provisoire. Certaines démarches peuvent demander jusqu'à 8 jours ouvrés.

Côté prix, les frais de service s'ajoutent aux taxes, qui restent identiques à celles de la voie officielle : 44,90 € pour un changement d'adresse, 54,90 € pour un duplicata, 34,90 € pour une déclaration de cession, et de 44,90 à 99,90 € pour un changement de titulaire selon le montant de la taxe régionale. Le paiement en 3 ou 4 fois est possible pour les achats de 150 à 500 €.

La voie officielle reste gratuite, hors taxes. Le changement d'adresse y est même gratuit dans la limite de trois déclarations par certificat, selon service-public.gouv.fr. Le recours à un professionnel se justifie donc surtout quand le code manque et qu'aucune des deux voies gratuites ne fonctionne : démarche pour un tiers, adresse périmée, nouveau code jamais reçu.
